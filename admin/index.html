📖 How to Upload Files to GitHub

Step 1 — Create a GitHub Repository
Go to github.com/new, create a public repo named e.g. studyhub-resources.
Step 2 — Organise your PDFs
Suggested folder structure:
notes/science/ch01-chemical-reactions.pdf
notes/maths/ch01-real-numbers.pdf
practice/science/ch01-practice.pdf
solutions/science/ch01-solutions.pdf
textbooks/science/ch01-textbook.pdf
Step 3 — Upload via GitHub Web UI
Open the folder in your repo → click Add file → Upload files → drag & drop your PDFs.
Step 4 — Get the Raw URL
Click the file in GitHub → click Raw → copy the URL.
It looks like:
https://raw.githubusercontent.com/yourname/studyhub-resources/main/notes/science/ch01.pdf
Step 5 — Add to Admin Panel
Paste that URL in the Add Resource tab above.
Step 6 — Deploy on GitHub Pages
Go to your website repo Settings → Pages → Source: Deploy from a branch → main.
Your site will be live at https://yourname.github.io/studyhub/
🔑 Changing the Admin Password
Open assets/js/data.js and update ADMIN_HASH. Run this in the browser console to generate a hash:
crypto.subtle.digest('SHA-256',
  new TextEncoder().encode('YourNewPassword'))
.then(b => console.log([...new Uint8Array(b)].map(x=>x.toString(16).padStart(2,'0')).join('')))
